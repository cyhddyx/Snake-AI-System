# 基于 BioCLIP 2 的蛇类物种分类模型训练报告

## 1. 引言

本报告记录基于 BioCLIP 2 大规模视觉-语言模型的蛇类物种细粒度分类任务训练过程。该任务来源于 SnakeCLEF 2023 竞赛，目标是对蛇类图像进行 1,784 个物种类别的识别。考虑到蛇类物种间形态高度相似、类间差异小、类内差异大等特点，本工作采用在大规模生物学图像上预训练的 BioCLIP 2 作为视觉编码器，通过线性探测（Linear Probing）策略在 SnakeCLEF 2023 数据集上进行迁移学习。

## 2. 数据集

### 2.1 数据来源与规模

实验使用 SnakeCLEF 2023 官方提供的三个数据子集：

| 数据子集 | CSV 文件 | 样本数 | 物种种数 |
|----------|----------|--------|----------|
| iNaturalist 训练集 | `SnakeCLEF2023-TrainMetadata-iNat.csv` | 154,301 | 1,784 |
| HM 补充训练集 | `SnakeCLEF2023-TrainMetadata-HM.csv` | 13,843 | 889 |
| 验证集 | `SnakeCLEF2023-ValMetadata.csv` | 14,117 | 1,599 |

每条样本包含字段：`observation_id`（观测 ID）、`binomial_name`（物种学名）、`image_path`（图片相对路径）、`class_id`（类别编号）、`code`（地理编码）等。

### 2.2 数据预处理

训练脚本（`finetune_snake.py`）在数据集初始化阶段对原始 CSV 进行文件完整性校验，逐条检查 `image_path` 对应的图片文件是否实际存在于磁盘，自动剔除缺失或路径不匹配的样本。该过滤步骤对训练稳定性具有重要意义——缺失图片若在 DataLoader 阶段才被发现，将导致批次内出现随机噪声替代样本，严重降低模型收敛质量。

验证集评估时（`evaluate_bioclip2.py`），额外过滤训练集中未出现的物种类别，确保分类头输出维度与训练集一致，避免索引越界错误。

输入图像的预处理流水线由 BioCLIP 2 配套的 `preprocess_train` 和 `preprocess_val` 变换完成，包含缩放至 224×224、标准化等标准操作。

## 3. 模型架构

### 3.1 骨干网络：BioCLIP 2

BioCLIP 2 是由 Imageomics 研究团队发布的面向生物学领域的视觉-语言预训练模型，基于 Vision Transformer（ViT）架构。模型以 224×224 的 RGB 图像为输入，经 ViT 编码后输出 768 维特征向量。该模型在大规模生物学图像-文本对（涵盖动植物、真菌等超过 45 万科）上进行对比学习预训练，具备强大的细粒度生物形态特征提取能力。

### 3.2 分类头设计

在线性探测阶段，冻结 BioCLIP 2 全部参数，仅在编码器之上添加一个可训练的线性分类层：

$$
\mathbf{z} = \frac{\text{BioCLIP}(\mathbf{x})}{\|\text{BioCLIP}(\mathbf{x})\|_2}, \quad \hat{\mathbf{y}} = \mathbf{W} \mathbf{z} + \mathbf{b}
$$

其中 $\mathbf{W} \in \mathbb{R}^{1784 \times 768}$，$\mathbf{b} \in \mathbb{R}^{1784}$，总计约 **137 万可训练参数**（$768 \times 1784 + 1784 \approx 1.37\text{M}$）。

在每批图像经骨干网络提取特征后，对特征向量进行 L2 归一化处理，再送入线性分类头。这一设计使特征落在单位超球面上，有助于稳定训练并提升类别间可分性。

## 4. 训练策略

训练分为两个阶段：第一阶段侧重快速验证可行性并建立基准，第二阶段引入更完善的训练策略以充分挖掘模型性能。

### 4.1 第一阶段：基准训练（`finetune_snake.py`）

第一阶段的训练配置见表 1，目标是快速建立线性探测的性能基线。

**表 1：第一阶段训练超参数**

| 超参数 | 取值 | 说明 |
|--------|------|------|
| 优化器 | AdamW | — |
| 学习率 | $1 \times 10^{-3}$ | 较高的初始学习率 |
| 批次大小 | 256 | 较大批次以加速训练 |
| 训练轮次 | 10 → 30 轮 | 初始 10 轮后继续训练至 30 轮 |
| 学习率调度 | CosineAnnealingLR | $T_{\text{max}} = 20$ |
| 损失函数 | CrossEntropyLoss | 无标签平滑 |
| 数据并行 | 8 个工作进程 | — |
| 验证集 | 无 | 以训练损失为监控指标 |
| 模型选择 | 依据训练 Loss | 最佳 Loss 基准初始为 2.28 |

第一阶段的特点与局限：

- **无验证集分离**：整个训练集直接参与训练，以 epoch 平均损失作为模型择优依据。此策略的好处是最大化训练数据利用率，但缺乏对泛化性能的直接衡量。
- **无混合精度训练**：全程使用 FP32 精度，训练速度受限于显存带宽。
- **无梯度裁剪**：在 1,784 分类任务中，梯度偶尔出现尖峰，可能导致训练不稳定。

第一阶段训练至第 10 轮时保存了中间检查点（`bioclip2_snake_epoch_10.pth`），之后继续训练至 30 轮。训练损失在初期快速下降后渐趋平缓，表明线性分类头已接近该配置下的收敛状态。

### 4.2 第二阶段：策略增强训练（`train.py`）

在第二阶段中，对训练策略进行了全面升级，引入验证集切分、标签平滑、混合精度训练、梯度裁剪、早停机制等模块，以解决第一阶段暴露的问题。

**表 2：第二阶段训练超参数**

| 超参数 | 取值 | 说明 |
|--------|------|------|
| 优化器 | AdamW | — |
| 学习率 | $1 \times 10^{-4}$ | 较第一阶段降低一个数量级 |
| 权重衰减 | $1 \times 10^{-4}$ | L2 正则化 |
| 批次大小 | 128 | 兼顾显存与梯度稳定性 |
| 训练轮次 | 0 → 30 轮 | 从检查点恢复后继续训练 |
| 学习率调度 | CosineAnnealingLR | $T_{\text{max}} = 30$，$\eta_{\text{min}} = 10^{-6}$ |
| 损失函数 | CrossEntropyLoss | 标签平滑 $\epsilon = 0.1$ |
| 梯度裁剪 | 最大范数 1.0 | 防止梯度爆炸 |
| 混合精度 | 自动混合精度 (AMP) | CUDA 可用时启用 |
| 验证集 | 90/10 随机切分 | 固定随机种子保证可复现性 |
| 早停 | patience=5，min_delta=0.001 | 验证精度不再提升时停止 |
| 加载策略 | 从最佳检查点恢复 | 含优化器/调度器状态 |

#### 4.2.1 标签平滑（Label Smoothing）

对于 1,784 类的细粒度分类任务，标签平滑（$\epsilon = 0.1$）对缓解过拟合和提升泛化性能尤为关键。原始 one-hot 标签在如此高的类别数下容易鼓励模型对训练样本产生过度自信的预测，导致验证集上的校准偏差。标签平滑将目标分布从 one-hot 修改为：

$$
q'(k|x) = (1 - \epsilon) \cdot \mathbb{1}_{k=y} + \frac{\epsilon}{K}
$$

其中 $K=1784$，$\epsilon=0.1$。这一技巧有效抑制了模型将概率质量过度集中于少数类别的倾向。

#### 4.2.2 混合精度训练（AMP）

启用 PyTorch 的自动混合精度（Automatic Mixed Precision），在兼容 CUDA 核心上使用 FP16 进行前向和反向传播中的大部分计算，同时以 FP32 保留关键权重。配合 `GradScaler` 动态调整损失缩放因子，确保小梯度值不会在 FP16 下溢出为 0。这一优化在不降低模型精度的前提下显著提升了训练吞吐量并降低了显存占用。

#### 4.2.3 梯度裁剪与早停

梯度裁剪（`max_norm=1.0`）应用于分类头参数的梯度上，在 `scaler.unscale_` 还原精度后进行，防止单批次噪声样本引发的参数剧烈更新。早停机制监控验证集 Top-1 准确率：若连续 5 个 epoch 未出现超过 0.001% 的精度提升，训练自动终止，避免无效计算并保留泛化最优的检查点。

#### 4.2.4 断点续训与状态恢复

第二阶段从第一阶段的 `bioclip2_snake_epoch_best.pth` 检查点加载，不仅恢复分类头权重，同时恢复优化器动量状态、学习率调度器内部计数和已完成的 epoch 数。这一完整的状态恢复确保了训练的连续性，避免了直接加载权重后优化器状态不匹配导致的初期震荡。

### 4.3 两阶段训练对比分析

**表 3：两个训练阶段的策略对比**

| 维度 | 第一阶段 | 第二阶段 |
|------|----------|----------|
| 学习率 | $10^{-3}$ | $10^{-4}$ |
| 批次大小 | 256 | 128 |
| 验证集监控 | 无 | 90/10 切分 |
| 标签平滑 | 无 | $\epsilon = 0.1$ |
| 梯度裁剪 | 无 | max_norm = 1.0 |
| 混合精度 | 无 | AMP (FP16) |
| 早停 | 无 | patience = 5 |
| 模型择优指标 | 训练 Loss | 验证集 Top-1 Acc |
| 调度器范围 | $T_{\text{max}} = 20$ | $T_{\text{max}} = 30$，$\eta_{\text{min}} = 10^{-6}$ |

第一阶段使用较大的学习率（$10^{-3}$）和批次大小（256）以快速收敛，适合探索阶段。第二阶段将学习率降至 $10^{-4}$、批次缩小至 128，配合标签平滑、梯度裁剪和早停等正则化手段，更注重模型的泛化能力与训练稳定性。余弦退火调度器将学习率从初始值平滑衰减至接近零，帮助模型在训练后期精细收敛。

## 5. 实验结果

### 5.1 最终训练结果

第二阶段训练收敛后，在训练集上的最终指标为：

| 指标 | 数值 |
|------|------|
| 训练 Top-1 准确率 | **~63%** |
| 训练损失 | **~1.x** |

在 1,784 个蛇类物种的分类任务中，该准确率反映了模型在训练集上的拟合程度。需指出的是，线性探测方案仅训练约 137 万参数的线性分类头，而骨干网络保持冻结，模型的整体表征能力受限于 BioCLIP 2 预训练特征的质量。考虑到蛇类物种间极为相似的体态特征（如多种蝮蛇仅在鳞片排列和颜色细节上存在差异），该结果已初步验证了 BioCLIP 2 特征在细粒度蛇类识别中的迁移价值。

### 5.2 检查点管理

训练过程中保存了三类关键检查点：

| 检查点文件 | 用途 |
|------------|------|
| `bioclip2_snake_epoch_10.pth` | 第一阶段第 10 轮中间检查点 |
| `bioclip2_snake_best.pth` | 验证集精度最优的模型权重（推理部署使用） |
| `bioclip2_snake_last.pth` | 最近一轮的断点续训检查点（含完整训练状态） |

其中 `bioclip2_snake_best.pth` 和 `bioclip2_snake_last.pth` 保存了完整的训练状态（分类头权重、优化器状态、调度器状态、epoch 计数、最佳验证精度），支持任意时刻的断点续训。

## 6. 推理增强

为提高实际部署时的预测准确率，在推理脚本中引入了两类增强策略。

### 6.1 地理分布过滤（Geographic Prior）

`text.py` 中实现了基于先验地理分布的概率重加权机制。该模块从训练集 CSV 中提取每个物种的已知分布国家/地区列表，在推理时允许用户输入图像拍摄地（国家名称），据此对分类头输出的概率进行后处理：

- 若某物种的已知分布记录**包含**用户指定的地区，其概率乘以 **1.2**（鼓励）
- 若某物种的已知分布记录**不包含**用户指定的地区，其概率乘以 **0.001**（近乎排除）

这一策略利用了蛇类地理分布的高度地域性——许多蛇种仅分布于特定大陆或国家，地理位置信息可作为强先验约束大幅缩小候选物种范围，有效抑制了形态相似但地理不重叠的物种的误判。

### 6.2 测试时增强（Test-Time Augmentation, TTA）

`text.py` 的预测过程中，对每张输入图像同时执行原始图像和水平翻转图像的推理，取两者的平均概率作为最终预测。水平翻转对于蛇类识别是安全的增强操作（蛇的形态在水平翻转下不变），且计算开销可控（仅增加一次前向传播），能以较低成本提升预测鲁棒性。

## 7. 总结与改进方向

### 7.1 工作总结

本文档记录了一个基于 BioCLIP 2 的 1,784 类蛇类物种分类模型的完整训练过程。核心技术要点包括：

1. **线性探测迁移学习**：利用 BioCLIP 2 在大规模生物学数据上习得的通用视觉表征，仅训练轻量线性分类头，显著降低计算开销（可训练参数量约 137 万）。
2. **两阶段渐进式训练**：第一阶段以较高学习率快速收敛至可行区间，第二阶段全面引入正则化与训练优化策略（标签平滑、梯度裁剪、混合精度、早停）以提升泛化性能。
3. **推理端增强**：结合地理分布先验与测试时增强技术，在实际部署中进一步提升预测精度与鲁棒性。

### 7.2 潜在改进方向

1. **骨干网络微调**：当前线性探测完全冻结了骨干网络。在分类头收敛后，可解冻 ViT 的最后若干层进行端到端微调（如仅解冻最后 2-4 个 Transformer Block），以将生物学通用特征进一步适配到蛇类的特定形态空间。此步骤需要更小的学习率（如 $10^{-5} \sim 10^{-6}$）以避免灾难性遗忘。

2. **数据增强策略**：当前仅使用 BioCLIP 2 内置的标准预处理。可引入更多蛇类特定的数据增强，如随机裁剪（RandAugment）、色彩抖动（Color Jitter）、随机擦除（Random Erasing）等，以增强模型对不同拍摄条件（光照、角度、背景）的鲁棒性。

3. **长尾分布处理**：SnakeCLEF 2023 数据集中不同物种的样本数量极不均衡（部分稀有物种仅有个位数样本）。可引入类别加权损失（Class-Balanced Loss）、重采样策略或双阶段训练（先训练头部类别、再在全部类别上微调）来缓解长尾效应。

4. **多尺度推理**：在推理阶段采用多尺度裁剪（Multi-Scale Crop）或多模型集成，可进一步提升 Top-1 准确率。

5. **整合 HM 补充数据集**：当前训练仅使用了 iNaturalist 训练集。HM 补充数据集的 13,843 张图像可作为额外训练数据，通过联合训练或课程学习策略引入，有望提升覆盖物种的识别精度。

6. **对比学习再训练**：若具备充足的计算资源，可在 SnakeCLEF 数据集上对 BioCLIP 2 进行领域适配性的对比学习微调（使用蛇类图像-文本对），再基于适配后的特征进行线性探测，预期可获得更大幅度的性能提升。
